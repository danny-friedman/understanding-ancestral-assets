Privacy and data use

Understanding Ancestral Hosted Upkeep is a private tool used by the site's owner. Updated October 26, 2026.

Data accessed and purpose

The main worker reads pending Blogger comments, including their author, content, publication time and identifiers, so the owner can review them. It reads private GitHub Actions run reports to check site health, certificate expiry and monitoring coverage. A separate worker reads the privacy, embedding, processing and regional restriction settings of ten YouTube videos belonging to the owner.

Storage and notifications

The main worker creates dated reports in an owner-private Google Drive folder. Its Drive permission is limited to files created or opened for the app; it does not receive general access to the owner's Drive. Reports are retained until the owner removes them. Script Properties store configuration, credentials, issue state and video settings. The video worker also writes settings-only reports to private execution logs, subject to Google's log retention.

Email alerts go only to the owner's configured address. They can include comment authors, findings and links to private reports. The workers can send email but cannot read Gmail. They do not automatically publish, delete or mark comments as spam, and do not change videos.

Sharing and service providers

Google hosts the workers, reports, authorization and email delivery. GitHub hosts source and health reports, and receives authenticated workflow requests. The workers do not send Blogger comment data or YouTube account data to GitHub. Google user data is not sold, used for advertising or used to train AI models by these workers. This use of Google user data follows the Google API Services User Data Policy, including its Limited Use requirements.

Control and access

Only the owner has access to the script projects and report folder. The owner can revoke authorization in Google Account connections, remove the Apps Script triggers and delete retained reports or stored script state. Revoking authorization stops future Google API access; it does not remove previously saved reports. The owner can revoke the dedicated GitHub token separately.

Visitors do not authorize this tool and this information page has no analytics, forms or cookies added by the tool. GitHub Pages and linked services operate under their own policies. Questions about the tool can be raised with the owner through the blog.
