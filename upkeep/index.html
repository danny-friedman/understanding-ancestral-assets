Understanding Ancestral Hosted Upkeep

A private maintenance tool for the owner of Understanding Ancestral Recall.

Two Google Apps Script workers check the site's retained health reports, pending Blogger comments and the settings of ten embedded YouTube videos. They email the owner when a new problem needs attention or an earlier problem clears. They run on Google's servers.

The workers read Blogger and YouTube data. They do not edit posts, moderate comments, change video visibility or deploy the blog. Video settings and public metadata do not establish anonymous playback.

The main worker saves reports in an owner-private Google Drive folder and can request an existing GitHub health workflow if its report is missing. The separate video worker has no Drive or GitHub access.

This page describes the tool. It offers no sign-in, installation, public application endpoint or account access to visitors.
